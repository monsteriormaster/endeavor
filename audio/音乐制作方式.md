## 0. 一句话

**符号作曲 + 固定音源渲染**：用 Python 按规则写谱 → 生成 MIDI → 交 **MuseScore 4 真音源**渲染 → **wrap-around 折成无缝循环** → 落 **PCM16 / 44.1 kHz / 立体声 WAV** → 放进 `audio/bgm/` → Godot 按场景自动切换。

**不用 AI 生成音频**——AI/脚本只产出**谱面**，音色由渲染器与 GM 配器决定。（`design/音频设计圣经.md` §5 的原始口径：「AI 写谱（符号生成）+ 自渲染」。）

## 2. 三条硬约束（不是风格偏好，是「不这么做就坏」）

### 2.1 同长 · 同循环点（族 A 内部可任意衔接）
族 A 每一首必须：`BPM = 108`、`32 小节`、`TOTAL = 3136000` 样本 = **71.111111 s**，**逐样本同长**。
外加 J1–J5 五条：调式外音 = 0；8 句落音向量逐句相同；第 32 小节末音 = 徵；核心动机音级集合 `{2,4,7}` 在 8 句全部出现等。
**明细见 `design/族A_六图变奏规格.md` §0。**

> 「**落音是接口，装饰是自由**」：允许加花 / 减花 / 加密 / 换乐器 / 移八度，**唯独句末两拍的落音不许动**。

### 2.2 无缝循环的判据
```
| x[0] − x[-1] |  ≤  信号自身相邻跳变的 P99.9
```
任何真音源渲染都会在最后一个音后留混响尾。直接截前 71.111 s ⇒ 循环点一次「咔」。
⇒ 渲染时**多留 ≥1 小节（空小节即可）**，再把「超出循环长度的那部分样本」**叠加**回开头（**叠加，不是替换**）—— 尾巴正好落在下一圈该在的位置。

### 2.3 调式与音集（族 A）
- 一律 **1 = G 的徵调式**（主音 = 徵 = D）：音集 `{G A B C D E F#}`，与族 A 的和声材料对齐。
- 五声骨干 `{D E G A B}`；偏音 `C`（清角） / `F#`（变宫），**占比 ≤ 8%**。
- 和声池 `{D, G, Am, Em}`，**禁用 A 大三** —— 它带 C#，会直接破坏「调式外音 = 0」。
- ⛔ 不许：换调式（Dorian/Aeolian 禁用）、改 BPM、改小节数、改落音、加调外音。

### 2.4 MusicXML 支线（只在「要写微音分」时才用）

绝大多数曲子走 MIDI 就够。**唯独要表达 cents 级失谐**（走音 / 失谐机器 / 微音调）时，MIDI **做不到**：

| 事实 | 实测依据 |
|---|---|
| **MIDI 表达不了 cents**：MuseScore 导入 MIDI 时**直接忽略 pitch bend**（+14 cents 实测 +0.00） | `debug/_probe_microtone.py` |
| **MusicXML 的小数 `<alter>` 可以**：`alter=0.14 → +13.04 cents`、`0.15 → +13.92 cents` | `debug/_probe_microtone2.py` |
| 🔴 **MusicXML 必须显式写 tempo**：缺 `<metronome>`/`<sound tempo>` 时 MuseScore 按**默认 120 BPM** 渲染，曲子会快 11% 且**零报错** | 见 `design/出现过的问题档案.md` **G-01** |

⇒ 走音轨的落法是：**自己写一个 MusicXML 输出器**（`design/make_commercial_music.py` 里有可复用的 `write_musicxml()` + `xml_note/xml_chord/xml_rest`），
渲染前**先量长度**（渲染长度 ≥ 谱面长度 + 混响尾），再折叠。
⚠️ 同一首曲子的**各条 stem 必须用同一个 alter**：一轨走音、一轨不走，同音相遇会有拍频。

## 3. 交付格式与目录

| 项 | 规格 |
|---|---|
| 容器 / 位深 | `.wav` **PCM 16-bit**（**禁 Ogg**：Vorbis 有 encoder delay/padding，天生非采样级无缝） |
| 采样率 / 声道 | **44100 Hz / 立体声** |
| 长度（族 A） | **3136000 帧 = 71.111111 s** |
| 放置 | `audio/bgm/` —— **只放入库成品** |
| 命名 | 族 A：`family_a_<场景>.wav`；其他：`bgm_<用途>.wav` |

### Godot 导入参数（⚠️ **新导入的 WAV 默认是错的**）

`.import` 的 `[params]` 必须满足：

```ini
edit/loop_mode=2      ; Forward。⚠️ 1-based：
                      ;   0 = Detect From WAV（我们程序生成的 wav 没有 smpl 块 ⇒ 等于「关闭」）
                      ;   1 = Disabled ｜ 2 = Forward ｜ 3 = Ping-Pong ｜ 4 = Backward
compress/mode=0       ; PCM 无损。默认 2 = QOA（有损）
```

**怎么证明改对了**：看 `.godot/imported/*.sample` 的**体积** —— 本项目 3136000 帧立体声应为 **12,544,407 B**；没改之前只有 ≈ 2.53 MB。**光看 `.import` 看不出来。**
（`AudioManager._ensure_looping()` 兜了一道「没配循环就补 Forward + 告警」，但改素材才是正解。）

## 4. 引擎侧（播放与音量）

`script/audio_manager.gd`（autoload，必须排在 `Settings` **之后**）：

- **场景映射** `SCENE_BGM`（**13 条**）：`loading`/`selection` → `bgm_title.wav`（「黎明启程」）；`tutorial_1` → `bgm_tutorial.wav`（「旅途开始」）；`main`/`hospital`/`home`/`plaza`/`prison`/`transport`/`school`/`orphanage`/`theater` → 族 A（九首）；`commercial` → `bgm_commercial.wav`（「街头手摇风琴圆舞曲」，**2026-10-08 起为正式曲**，不再是占位）。
- **未列入的场景 = 该区域没实装音乐 → 淡出停止**（**不沿用上一首**）。**现只剩 `church` 一条**（2026-10-17 剧院接线后）。
- **同曲不重播**：切场景时目标曲 == 当前曲 → 什么都不做。这是「音乐跨场景不断」的核心。
- **冷启动**：`run/main_scene` 由引擎直载、不发 `scene_entered` ⇒ `_ready()` 末尾自己补一次。

**音量接口**（五路 `Master / Music / SFX / UI / Ambience`，**名字大小写不敏感**）：

```gdscript
AudioManager.set_bus_volume("Music", 0.5)   # 线性 0..1
AudioManager.get_bus_volume("Music")
AudioManager.set_muted(true)                # 一键静音 = Master 总线 mute 标志
AudioManager.is_muted()
```

- 音量按 **bus 名（String）** 存，不按索引。
- 落盘在 `user://settings.json`（扁平键 `music_volume`…），由 `script/settings.gd` 用 **S1 原子写**（tmp → 读回逐字节校验 → rename）负责。
- ⚠️ **每次 `set_bus_volume()` 都会落盘一次** —— 接设置滑杆时用 `drag_ended` 提交或做去抖，**不要挂 `value_changed`**。

## 5. 新增一首 BGM 的清单

1. **写谱**：在 `design/make_melody_liangzhu_v1.py`（主城主题）或 `design/make_scene_variants.py`（变奏场景表）里加事件；族 A 必须满足 §2 的硬约束。
2. **出 MIDI 并自检 GM program change** —— 不带 program change，MuseScore 会全按钢琴渲染且**不报错**（静默错）。
3. **渲染**：
   ```
   C:/Users/26464/miniconda3/python.exe design/_ms_pipeline.py <in.mid> <out_dir> 71.11111111111111 --label <名>
   ```
4. **自检**：接缝判据（§2.2）+ 峰值/削波 + 时长。
5. **入库**：复制进 `audio/bgm/`，改 `.import` 为 `loop_mode=2` + `compress/mode=0` 后重导。
   **判据（必须验）**：`.godot/imported/*.sample` 体积 = `帧数 × 声道 × 2 + 407`（本工程 1176000 帧立体声 = **4,704,407 B**）；没改之前只有约一半。**光看 `.import` 看不出来。**
6. **接线**：在 `SCENE_BGM` 加映射。
7. **验收**：跑 `res://debug/_audio_probe.tscn`（`--headless` 跑引擎自检段、`--windowed` 跑场景走查段）。

> **分支：如果这首曲子需要 cents 级失谐**（走音机器 / 微音调）→ 见 **§2.4 MusicXML 支线**：
> 走音轨改走 MusicXML（小数 `alter`），**必须显式写 tempo**，渲染后先量长度再折叠。

### 6.1 声部平衡微调（2026-10-17）

用户反馈「低音太明显，有点喧宾夺主」⇒ 量了三支尺子才定位到问题（详见 `design/_apply_voice_balance.py` 文件头），
结论是**低频/低中频某些频段比族内中位谱偏多 3 ~ 34 dB**。处理方式：

| 口径 | 值 | 为什么 |
|---|---|---|
| 目标谱 | 族 A 九首**逐频点中位数** | 同族互比，不引入外部审美 |
| **只削不抬** | — | 补空频段 = 凭空造音色，那才是「大改」 |
| 校正量 | `−clamp(0.6 × Δ, 0, 3.5)` dB | 六成；偏多 5 dB 削 3，偏多 30 dB 也只削 3.5 |
| 频段 | **只动 ≤ 400 Hz** | 削高频会让低频显得更重，正好反着来 |
| 实现 | **频域相乘**（零相位 · 循环卷积） | 帧数不变 + **首尾仍连续**；`lfilter` 那类 IIR 会引入开头瞬态，直接毁 loop 点 |
| 收尾 | 整曲增益补回 **−19.63 LUFS** | 九首响度必须仍然一致 |

实际削减（dB，1/3 倍频程）：剧院 `160Hz −3.1 / 250Hz −2.2`；main·plaza·prison·transit `80–100Hz −3.5`；
hospital `250Hz −3.3`；home `200Hz −1.9`；orphanage `250Hz −2.2`；school `250Hz −1.4`。
**非族 A 三首不动**（曲风独立，没有同族基线；且它们低频相对中频本来就更轻，见 §6 表）。

- **全库 12 首**（族 A 九 + 开场两 + 商业街一）响度**互差 ≤ 0.03 LU**（−19.60 ~ −19.63）；削波 **0**。
- ⚠️ **量完别急着削**：本轮前两支尺子（低频能量占比 / 掩蔽时间）都**量不出问题** —— 剧院两项指标都正好等于族内中位数。
  真正跳出来的是**谱形偏离**。总量一样不代表听感一样。
- 测量口径：整响度 = ITU-R BS.1770（K 加权 + 400 ms 块 / 100 ms 步长 + 绝对 −70 / 相对 −10 双门限，44.1k 先重采样到 48k；**声道功率求和，不是求平均**）。
  复算工具：`design/measure_lufs.py`（`python design/measure_lufs.py [目录]`）—— 三套独立实现互证过，可直接拿来当回归尺子。
  ⚠️ 量具最常见的错法就是把「声道求和」写成「求平均」，会整体低 3.01 dB。**数字对不上时先怀疑尺子。**
- 探针验收：`--headless` **116 项 0 失败** / `--windowed` **214 项 0 失败**（v6，2026-10-17 复跑，14 次真切场景走查，含剧院起播 + 相位续播 + 商业街同曲不重播）。
  （2026-10-08 那次是 112 / 204，v5。）

   **要不要上「stem 并发播放」（引擎侧新功能）由用户定。**
6. **duck / stem 组 / 叠加层** 尚未开始，属 `音频系统策划案.md` §3 / §8.8 的后续阶段。
   ✅ **SFX / UI 音效已于 2026-10-13 落地**（设计圣经 §3.6 的 P0 全套 10 项 / 含变体 15 条）：
   素材在 `audio/ui/`，生成器 `design/make_ui_sfx.py` + 后处理 `design/_ms_sfx_pipeline.py`，
   验收报告 `design/UI音效_验收报告.md`。
   ⚠️ **它的音色路线与 BGM 不同**，别拿本文档的流程去套：UI 音效是**拟音**性质
   （木质「嗒」、金属「叮」、纸张摩擦）；
   渲染后要**裁到设计时长 + 逐条归一化 + 转单声道**，不是本文档的 wrap-around 无缝循环。
   ⭐ **2026-10-13 第二版起，音色全部改用中频音高乐器**（Woodblock 115 / Kalimba 108 /
   Music Box 10 / Celesta 8 / Harp 46 / Vibraphone 11 / Marimba 12 / Cello 42 /
   Steel Drums 114 / Fret Noise 120），**整条 GM 打击乐声部撤掉**。原因是实测第一版
   用的 Maracas / Guiro / Claves / Cabasa 那套宽带噪声打击乐 `>4 kHz` 能量占 65%，
   而现役 BGM 是 0.0-0.1%，两边差一个数量级，听感就是「音效浮在音乐外面」。
   ⇒ **这也说明本文档 §6 的「真音源」不等于必须用打击乐**：与 BGM 共存的关键是
   **频段落在同一个区间**，其次是电平。电平口径见 `音频系统策划案.md` §12.6.1。
