## 二、逐款读图结论

### 《苏丹的游戏》——**彩色场卡**（正解，我第一版说错了）
手牌区实际长这样（`r_sudan_hand.png`，取自 `ss00`）：
- **整片高饱和彩色场**做卡面（金 / 绿 / 米），**带金属闪粒、粗糙肌理**，不是平涂
- **细黑键线**勾外轮廓 + **内侧一条细线**；圆角
- **卡名用深色字直接压在顶部场内**（「秘密」「梅姬」），**没有独立名称条**
- 下部为**线稿插画**，同色系压深
- ⚠️ 另有一类**特殊「苏丹卡」**（`r_sudan_full.png`，取自 `ss06`）：近黑底 + **金色缠枝纹带**（金底黑线）勾出**尖拱窗**，拱内深绿暗花纹场 + 象牙色蚀刻插画。**这是特殊卡，不是普通手牌**——我上一版把两者混为一谈了。

### 《月圆之夜》——**分层版式卡**（四个里唯一自带名称条）
`zoom_yueyuan_pick.png` / `r_yueyuan4.png`（取自 `ss00` / `ss04`）：
1. 卡身**近黑**；**厚黑边**（约卡宽 7%）
2. 黑边上 **一条奶白细内线**沿内缘一圈，**四角各有奶白细卷草**
3. 正下方 **类型色实心名称条**（「抄写笔」=墨绿，「许愿星灵」=蓝灰），**白字**，约占卡高 11–12%
4. **圆形立绘窗**：奶白细圈，**圈内芥末金**（带中心微光）
5. **五枚金色五角星**压住圆的底缘
6. 底部**深色文本带**，白字 + 红/蓝关键词
- 比例：手牌被屏幕下缘裁切，**只能给出上限**——宽 164px / 可见高 ≥223px → **宽高比 ≤ 0.74**，真实值无法从手牌量出。

### 《忘却前夜》——**满版出血卡**
`zoom_morimens_hand.png` / `zoom_morimens_card.png`（取自 `ss03`）：
- **立绘满版出血**，画面直接就是卡面
- 边缘一条**极细金色哥特尖拱花边**（镂空尖拱纹样，非平直框带）
- **白字直接压在画面上**、无衬底、无名称条、无文本框
- 卡形偏高瘦

### 《王者万象棋》——**徽章式立绘卡**
`sheet_single_cards.png` / `r_wangzhe.png`（取自官网 `wxq_17.png`，**198×253 原生，宽高比实测 0.78**）：
- **圆角矩形**；最外**深蓝细边** → **厚金双线框**（四角有小菱形饰）→ 立绘**满版**
- 左上：**菱形阵营徽**；右上：**圆角方形字母徽**
- 左下：**三枚深底圆角方形技能图标**；右下：**Lv** 金字
- **无名称条、无文本框**

## 三、四个参照的共同点（这才是"卡牌"与"相框"的分界）

| 特征 | 苏丹 | 月圆 | 忘却 | 万象棋 |
|---|---|---|---|---|
| 有独立名称条 | ✗ | **✓** | ✗ | ✗ |
| 立绘满版出血 | ✗（拱窗） | ✗（圆形窗） | **✓** | **✓** |
| 有文本框 | ✗ | ✓ | ✗ | ✗ |
| 边框带花纹 | ✓（拱带） | ✓（角卷草） | 极细 | 厚金框 |
| 实测宽高比 | — | ≤0.74 | 高瘦 | **0.78** |

→ **没有一款是"厚边框 + 中间一个空槽"**。四款的共同点是：**卡面本身被图案/色场/立绘切分成明确的区**，边框只是区的边界。这正是之前被否的那几张（v1~v4）缺的东西。

## 四、对着原图出的那一张

选 **《月圆之夜》** 作基础，理由：**四款里唯一自带「名称条 → 立绘窗 → 星级 → 信息带」四段版式的**，而 `card_chip.gd` 恰好需要「立绘区 + 名称区」两段——其余的（满版出血 / 徽章式）都得改结构才能用，那就不叫"抄"了。

| 文件 | 说明 |
|---|---|
| `卡面_月圆之夜_v1.png` | 540×954（**归一比例 0.5662**，目标 0.5660。原图 0.682 → 居中补上下边距） |
| `卡面_月圆之夜_v2.png` | 同上比例。**修正 v1 的错**：v1 把边框画成奶白底+深线（**反了**），v2 改回原图的**近黑底 + 奶白细内线 + 奶白四角卷草**，卡身也由墨绿改为近黑 |
| `对比_月圆之夜_三版.png` | **原图 / v1 / v2 三联**——最直观的验收图 |

**为什么不用图生图**：把别人游戏的实际卡面丢进去做 i2i，产出的是**对别人美术资产的直接衍生**，而且你之前也明确禁过 i2i。所以走**对着原图量结构 → 文生图复现**：版式、分带比例、配色全部从原图取，画面内容自己出。

**v2 与原图仍有的差距（我没藏）**：
1. 原图圆窗有**暖色径向光晕**，v2 是平涂芥末金
2. 原图四角卷草**更细更长**（真手绘），v2 偏简
3. 原图卡身有轻微暗角，v2 全平（**这条对我们是优点**，便于九宫格拉伸）

## 五、待讨论 / 待拍板

1. **就按《月圆之夜》这条做下去**，还是换一款（换的话我照同样流程：量原图 → 出图 → 三联对比）。
2. ⚠️ **名称条位置冲突**：月圆之夜的名字条在**顶部**，而 `card_chip.gd` 的 `VBoxContainer` 是 `[立绘 EXPAND_FILL][名字 SHRINK_END]` —— **名字在底部**。要照原图就得改 `card_chip.gd`（约 5 行，把 Label 提到 icon 之前）。**未动代码。**
3. **比例**：v1/v2 的归一都靠"补边距"，卡身只占成品宽度的 ~74%（原图本身是 0.682，我们是 0.566）。要么接受，要么按「顶条 / 中窗 / 底条」切三段九宫格（纵向拉伸只落在纯色区，两条高恒定）。
4. 星级 / 类型色 / 关键词高亮这些**额外信息位**，我们卡上要不要用（现在 `card_chip.gd` 只有立绘 + 名字）。
