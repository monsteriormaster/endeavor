# Endeavor · 项目经历

**回合制养成管理 RPG｜Godot 4.7｜单人完成策划与程序｜现有可玩 demo**

玩家在一座近似第一次工业革命时期的雾都里经营家业、结交人物、经历事件。所有行动由卡牌和骰子驱动，选择会留下长期后果。

## 设计工作

**行动与判定**

- 手牌即行动：卡牌拖入卡槽才触发行动，资源管理和时机取舍落在同一张牌上
- 骰子判定成败：投的是执行者的属性，养成路线直接改变掷骰期望

**事件与剧情**

- 触发器系统：用人物标记、物品持有、时间等条件组合出事件入口，玩家的选择写回标记，决定后续内容是否出现
- 已落地一条完整人物剧情线、家业经营主线和酒馆交涉支线，全程分支可选

**数值与数据**

- 角色、物品、经济、事件的数值全部自行拍板，落成 JSON 配置，改案不碰代码
- 自建 350 余项静态审计与自动回归探针，内容改动错漏在提交前被拦下
